# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities in `jak-plugins`, its bundled skills (`project-scaffolder`, `skill-factory`), or helper scripts under `skills/*/scripts/`.

Instead, report vulnerabilities privately to the repository maintainer via GitHub Security Advisories (`Security -> Advisories -> Report a vulnerability`) or by contacting **@SavEe2429** directly with:

- Target skill or adapter (`project-scaffolder`, `skill-factory`, `.claude-plugin/`, etc.)
- Clear reproduction steps or proof-of-concept payload
- Potential security impact (e.g., arbitrary command execution, path traversal, prompt injection)

We aim to acknowledge reports within 48 hours and coordinate a fix before public disclosure.
